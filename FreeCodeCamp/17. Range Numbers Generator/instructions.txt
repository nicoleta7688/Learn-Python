In this lab, you will build a range_of_numbers function that uses recursion to generate a list of numbers within a specified range.

For example:
- range_of_numbers(3, 9) should return [3, 4, 5, 6, 7, 8, 9].
- range_of_numbers(5, 5) should return [5].

Objective: Fulfill the user stories below and get all the tests to pass to complete the lab.

User Stories:
1. You should create a function named range_of_numbers with two parameters named start_num and end_num.
2. The function should return a list of consecutive integers that begins with start_num and ends with end_num, including both values.
3. The value of start_num will always be less than or equal to end_num.
4. Your function should use recursion by calling itself.
5. Your function should not use for or while loops, comprehensions, or the range() function.
6. When start_num equals end_num, the function should return a list containing start_num. This is the base case.
7. For the recursive case, the function should call itself with an argument that moves toward the base case, then add the current number to the returned list.
8. The function should not use global variables to store the returned list.

Tests:
1. You should have a function named range_of_numbers with parameters named start_num and end_num.
2. range_of_numbers(1, 5) should return [1, 2, 3, 4, 5].
3. range_of_numbers(6, 9) should return [6, 7, 8, 9].
4. range_of_numbers(4, 4) should return [4].
5. range_of_numbers(10, 15) should return [10, 11, 12, 13, 14, 15].
6. Your range_of_numbers function should call itself.
7. Your range_of_numbers function should not use loops, comprehensions, or the range() function.
8. Calling range_of_numbers(1, 3) should not affect a later call. After that call, range_of_numbers(6, 9) should still return [6, 7, 8, 9].
