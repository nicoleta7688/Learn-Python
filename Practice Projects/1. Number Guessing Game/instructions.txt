1. Number Guessing Game

Main focus: Loops, conditions, numeric input, simple state tracking, random values.
Project goal: Create a command-line game where the user tries to guess a hidden number within a defined range.

Core Requirements
    • The program should generate a hidden number inside a range shown to the user.
    • The user should be able to enter guesses until the correct number is found or the game ends.
    • After each guess, the program should tell the user whether the guess is too low, too high, or correct.
    • The program should count how many guesses were used.
    • The program should display a final result message when the game ends.

Validation Rules
    • Reject empty input and non-numeric input without crashing.
    • Reject numbers outside the allowed range and ask again.
    • Make sure repeated invalid input does not count as a real guess unless you intentionally decide otherwise and document that behavior.

Edge Cases to Test
    • The first guess is correct.
    • The user repeatedly enters invalid values.
    • The user guesses the same number multiple times.

Extra Challenges
    • Add difficulty levels with different ranges and maximum attempts.
    • Show a short performance message based on how many guesses were needed.
    • Allow the user to play multiple rounds and show total wins/losses at the end.

Completion rule: Consider the project complete only when normal input, invalid input, empty data, and at least three edge cases work correctly.
